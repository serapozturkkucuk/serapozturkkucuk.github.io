Projects

Every project starts with the business problem, not the tool. Each requirement is traced to a solution, alternatives are compared before building, and every change is tested on the path where it should work and the path where it shouldn’t.

Problems, causes and fixes are documented as they happen. Each case study covers the problem, the configuration, the testing and the lessons learned.
